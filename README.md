# tawasal-dev

This repository is the working development repo for Tawasal. It contains the full implementation work-in-progress: frontend (Next.js + TypeScript + Tailwind), API routes, server-side Socket/Signaling scaffolding, and SQL schema prepared for Supabase/Postgres.

Note: No secrets or production keys are stored here. Configure environment variables as documented in .env.example before running locally. For production, use Supabase project and host (Vercel or other) and set secrets there.

Work plan: develop in feature branches and open PRs to main Tawasal repo when features are ready.
